# Void Crest Compatibility 1.1.1

Version 1.1.1 replaces the remaining implementation-facing Base Crest names with the names players
see in Hollow Knight: Silksong.

## Changed

- Toolmaster is now presented as **Architect**.
- Spell is now presented as **Shaman**.
- Warrior is now presented as **Beast**.
- Cursed is no longer exposed as a Base Crest choice and is presented as **Witch** only where Void
  Crest 0.4.4 requires that private startup value.
- Removed a forgotten planning statement.

## Compatibility

- Existing configuration values migrate automatically.
- Architect, Shaman, Beast, and Witch were each verified through gameplay and runtime logs.
- Witch uses the real Witch/Whip attack provider after startup; Cursed is not treated as Witch's
  functional identity.
- The physical equipped crest remains Void while the selected provider supplies its compatible
  attacks and behavior.
- Dependencies are unchanged from 1.1.0.

## Updating

Replace the previous `VoidCrestMovesetCompat.dll` with the 1.1.1 DLL or update through the mod
manager. Existing configuration and save data do not need to be removed.

This release does not absorb or redistribute the original Void Crest mod. Void Crest by DerVorce
remains a required dependency.
