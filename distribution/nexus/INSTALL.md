# Installation

This archive is arranged relative to the Hollow Knight: Silksong game directory.

1. Install BepInEx and the required dependencies listed on the mod page.
2. Extract this archive into the Hollow Knight: Silksong game directory.
3. Confirm that the DLL is located at:
   `BepInEx/plugins/ManthisCo-Void_Crest_Compatibility/VoidCrestMovesetCompat.dll`
4. Start the game through the same modded profile or BepInEx launch method used for the dependencies.

Required mods:

- Void Crest by DerVorce
- Needleforge
- ModMenu

When updating, replace the existing compatibility DLL. Existing configuration is migrated by the
mod; do not delete configuration or save data unless a release note explicitly instructs you to.
